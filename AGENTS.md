# Confidentialité des données

- Ne jamais ajouter de données RH réelles au dépôt, y compris dans les tests, exemples, commentaires, captures ou journaux.
- Créer des identités, identifiants et situations salariales entièrement fictifs pour les tests. Ne pas recopier les valeurs d'un dossier de production.
- Les documents et historiques de production restent dans le stockage privé Supabase.
- Avant toute publication, vérifier les fichiers modifiés pour éviter l'inclusion de données personnelles ou de secrets.
